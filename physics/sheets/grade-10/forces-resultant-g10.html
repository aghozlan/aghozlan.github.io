Forces and the Resultant Force

Name: Class: Date: Score: ______ / 20
By the end of this session you can: name and represent the usual forces · find the resultant of collinear and perpendicular forces · use an orthonormal system to find Rx, Ry, then the magnitude and the direction of the resultant.
A force is an action that can change the motion of a body or deform it. It is a vector F→ with 4 characteristics:
  1. point of application (where it acts)
  2. line of action (its direction)
  3. sense (the arrow tip)
  4. magnitude in newtons (N), measured with a dynamometer
We draw it as an arrow whose length follows a scale.

Opposite directions

Any forces: use an orthonormal system (O, x, y)
  1. Project each force: Fx=Fcos⁡α, Fy=Fsin⁡α (α measured from the x-axis; a component is negative if it points toward −x or −y).
  2. Add: Rx=∑Fx and Ry=∑Fy.
  3. Magnitude: R=Rx2+Ry2.
  4. Direction: tan⁡θ=RyRx, θ from the x-axis.
Example: Rx=30 N, Ry=40 N: R=900+1600=50 N, tan⁡θ=4030, θ≈53°.
